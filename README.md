# Employees
Разработка информационной системы для хранения информации о сотрудниках предприятия
В данной информационной системе хранится: 
1. Список сотрудников.
2. Информация о трудовой деятельности каждого сотрудника:
- место работы;
- дата начала работы; 
- дата увольнения;
- должность.
3. Информация о детях сотрудников:
- ФИО ребенка;
- год рождения.
4. Информация о текущем окладе сотрудника.
